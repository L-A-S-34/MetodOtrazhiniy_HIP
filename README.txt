РЕШЕНИЕ СЛАУ МЕТОДОМ ОТРАЖЕНИЙ С ИСПОЛЬЗОВАНИЕМ HIP

Студент: Лизунов Артём Сергеевич 304 группа мехмат

Описание:
Программа решает СЛАУ методом отражений. 

Параллельная реализация метода отражений для решения систем линейных алгебраических уравнений (СЛАУ) на графических процессорах AMD с использованием AMD ROCm / HIP и компенсации погрешностей округления по алгоритму Кэхэна.

Архитектурные особенности GPU-реализации:
1) Распределение потоков «один поток — один столбец»
2)
 * В базовой гибридной версии SolveHIPKahan вектор отражения v вычислялся на CPU с двусторонней синхронизацией столбцов через hipMemcpy2D.
 * В финальной версии SolveHIPKahanGPUONLY генерация вектора v, коэффициента alpha и обновление правой части b полностью перенесены на GPU в отдельное ядро VectorWorkerGPUONLY. Оба ядра выполняются в едином последовательном потоке команд, что гарантирует аппаратную синхронизацию шагов без участия CPU и полностью устраняет трафик по шине PCI-Express во время прямого хода.
3) Вычисления проводятся в двойной точности double (64 бит), а высокая точность на плохо обусловленных системах достигается за счёт компенсации Кэхэна.

Структура:
- main.hip        : Главный управляющий модуль программы
- initHIP.h       : Инициализация матриц по формулам и чтение из файла
- SolveHIP.h      : Реализация метода отражений с использованием HIP
- README.txt      : Данное руководство
- msvc_defines.h  : Для корректной работы IntelliSense в Visual Studio

Сборка проекта:

  Прямая компиляция через hipcc (Windows / Linux)
Укажите целевую архитектуру вашего GPU в флаге --offload-arch (например, gfx1201 для Radeon RX 9070 XT):

hipcc main.hip -o solution_gpu --offload-arch=gfx1201 -O3

  Запуск генерации матриц по формулам (k = 1..4)
Синтаксис:

./solution_gpu <n> <m> <k>

n — размерность матрицы (n > 0)
m — количество выводимых элементов (m > 0)

Пример (матрица Гильберта размерностью 10000, вывод первых 5 элементов):

./solution_gpu 10000 5 4

Запуск с чтением матрицы из файла (k = 0)
Синтаксис:

./solution_gpu <n> <m> 0 <имя_файла>

Пример:

./solution_gpu 100 5 0 a.txt
